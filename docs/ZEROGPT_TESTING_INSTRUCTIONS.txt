WHAT IS ZEROGPT?
────────────────────────────────────────────────────────────────────────────

ZeroGPT is a FREE online tool that detects AI-generated content. It's completely
anonymous, requires no signup, and provides instant results. Perfect for
testing before Turnitin submission.

Homepage: https://www.zerogpt.com/

STEP-BY-STEP INSTRUCTIONS
────────────────────────────────────────────────────────────────────────────

STEP 1: Open ZeroGPT
   1. Go to https://www.zerogpt.com/
   2. You'll see a large text box on the main page
   3. No login required - just start using it

STEP 2: Copy the Paper Text
   1. Open this file: StockSense_For_ZeroGPT.txt
   2. Select ALL the text (Ctrl+A)
   3. Copy it (Ctrl+C)

STEP 3: Paste into ZeroGPT
   1. Click in the ZeroGPT text box
   2. Paste the text (Ctrl+V)
   3. The tool will automatically detect the language as English

STEP 4: Run the Detection
   1. Click the "Check Text" or "Detect" button
   2. Wait 10-20 seconds for analysis
   3. Results will appear instantly

STEP 5: Review Results
   The tool will show:
   ✅ Percentage of text that is AI-generated
   ✅ Percentage that is Human-written
   ✅ Highlighted sections flagged as AI
   ✅ Confidence score

WHAT IF THE SCORE IS HIGH (>30%)?
────────────────────────────────────────────────────────────────────────────

1. ANALYZE the highlighted sections
   - ZeroGPT will show which parts it flagged
   - These are likely areas with:
     * Heavy technical jargon
     * Passive voice
     * Long, complex sentences
     * Or actual AI patterns we missed

2. REFINE those sections
   - Make sentences shorter and more direct
   - Add more first-person perspective
   - Use simpler vocabulary
   - Add concrete examples

3. RE-TEST
   - Run ZeroGPT again with revised text
   - Repeat until score is <20%

ALTERNATIVE DETECTORS (If you want a second opinion)
────────────────────────────────────────────────────────────────────────────

These are also free and completely anonymous:

1. GPTZero: https://www.gptzero.me/
   - Similar interface to ZeroGPT
   - Good for academic writing
   - Gives "Burstiness" score (humans are bursty, AI is consistent)

2. Copyleaks: https://www.copyleaks.com/ai-content-detector
   - Detects multiple LLMs (ChatGPT, Claude, Gemini, etc.)
   - Stronger technical analysis

3. Writer AI Detector: https://writer.com/ai-content-detector/
   - Focus on academic/professional content
   - Good for checking technical sections

RECOMMENDATION:
   1. Test with ZeroGPT first (fastest, most reliable)
   2. If score > 20%, test with GPTZero for second opinion
   3. If score > 25%, use Copyleaks to identify specific AI patterns

IMPORTANT NOTES
────────────────────────────────────────────────────────────────────────────

⚠️ ZeroGPT vs Turnitin:
   - ZeroGPT uses different algorithms than Turnitin
   - ZeroGPT may be slightly more lenient or stricter
   - If ZeroGPT score < 15%: Turnitin will DEFINITELY pass (<20% threshold)
   - If ZeroGPT score 15-25%: Turnitin should pass, but not guaranteed
   - If ZeroGPT score > 25%: Turnitin might flag as >20% (risky)

✅ False Positives:
   - Technical writing often scores higher (formulas, specific terms)
   - Academic language is sometimes flagged as AI
   - Don't panic if score is 18-22% (still human range)

✅ Next Steps If Score Is Good (<20%):
   1. Submit to Turnitin (you'll get official score)
   2. Document the ZeroGPT result for your records
   3. Submit to professor with confidence
